# Active Ai

AI marketing workspace: turn a product into creatives, campaigns and insights.

## Stack
- Next.js 14
- React 18
- TypeScript
- Tailwind CSS

## Development

1. Install dependencies with `npm install`.
2. Copy `.env.example` to `.env.local` and configure providers.
3. Run `npm run dev`.

The repository currently contains the public marketing site, SaaS dashboard, product intelligence UI, product-analysis API, Creative Studio, campaigns and analytics foundations.

## Production

Configure the environment variables in your hosting provider, then run `npm run build` and `npm start`.

Never commit API keys or payment secrets.
